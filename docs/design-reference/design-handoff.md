# דירומקס — חבילת העברה לוורדפרס

חבילה מוכנה לבנייה: **ערכת עיצוב (theme) שלמה של וורדפרס**, שמייצרת בדיוק את האתר שאושר בעיצוב — כולל כל האפקטים, מעברי העכבר, הטבלה, האקורדיון והטופס.

---

## מה יש כאן

```
diromax-theme/            ← זו הערכה. להעלות אותה כמו שהיא לוורדפרס.
  style.css               ← כל העיצוב. 23 מקטעים ממוספרים, טוקנים למעלה.
  functions.php           ← אתחול, טעינת פונטים, גדלי תמונות
  header.php  footer.php
  front-page.php          ← עמוד הבית = עמוד ההשבחה
  index.php  single.php  page.php  404.php
  page-templates/         ← 5 תבניות עמוד (נבחרות מתוך עורך העמוד)
  template-parts/         ← מקטעים לשימוש חוזר
  inc/
    helpers.php           ← פונקציות עזר לתבניות
    content.php           ← כל הטקסטים של האתר במקום אחד (מסונן ב-filters)
    customizer.php        ← טלפון, וואטסאפ, מייל, אזור, תמונת הירו, מתגי תצוגה
    leads.php             ← קליטת לידים: שמירה בלוח הניהול + שליחת מייל
    projects.php          ← סוג תוכן "פרויקטים" עם תמונות לפני/אחרי
  assets/
    css/  js/diromax.js   ← שליחת טופס ב-AJAX והחלפה לפאנל תודה
    fonts/                ← Anomalia (3 משקלים)
    img/logo.jpg

reference/                ← העיצוב המקורי (HTML). פותחים בדפדפן להשוואה.
  Diromax.dc.html         ← האתר המאושר — מקור האמת לכל פיקסל
  Diromax Logo.dc.html    ← סבבי הלוגו
CLAUDE.md                 ← ההנחיות לקלוד קוד. להתחיל מכאן.
```

## התקנה — 6 דקות

1. **העלאת הערכה**  
   דחוס את התיקייה `diromax-theme` ל-ZIP והעלה: *עיצוב → ערכות עיצוב → הוספה → העלאת ערכה*. הפעל.

2. **יצירת 5 עמודים** (*עמודים → הוספה*), ולכל אחד לבחור תבנית מתוך "תכונות עמוד → תבנית":

   | כותרת העמוד | תבנית |
   |---|---|
   | ניהול השבחת נכסים | דירומקס — ניהול השבחת נכסים |
   | תיווך | דירומקס — תיווך |
   | שאלות ותשובות | דירומקס — שאלות ותשובות |
   | מאמרים | דירומקס — מאמרים |
   | צור קשר | דירומקס — צור קשר |

3. **עמוד בית**: *הגדרות → קריאה → עמוד ראשי קבוע* ← "ניהול השבחת נכסים".  
   (או להשאיר ריק — `front-page.php` מציג את עמוד ההשבחה בכל מקרה.)

4. **פרטי קשר**: *עיצוב → התאמה אישית → דירומקס — פרטי קשר*.  
   טלפון, וואטסאפ (פורמט 972541234567), מייל, אזור פעילות, וכתובת לקבלת לידים.

5. **תמונת הירו**: *התאמה אישית → דירומקס — תצוגה*. פורטרט 3:4, מוצגת בשחור־לבן.

6. **לוגו**: *התאמה אישית → זהות האתר → לוגו*. בלי העלאה — נטען הלוגו שבתיקיית הערכה.

**קישורים ידידותיים:** *הגדרות → קישורים ידידותיים → שם הפוסט*.

### מרווחים ומידות

- רוחב מקסימלי: **1280px**; עמודי טקסט צר: **960px**.
- מרווח צד (gutter): `clamp(18px, 4vw, 44px)`.
- ריווח אנכי למקטע: `clamp(56px, 6vw, 96px)` (`.dx-pad-lg`), וריאציות ב-`.dx-pad-md/sm/xs/cta/band/strip`.
- **גבולות:** 2px `#15171C` בין מקטעים ובכל מסגרת; 1px `#CFCDC8` בתוך מקטע.
- **אין border-radius בשום מקום.** אין צללים חוץ מ-`box-shadow` שמשמש כקו.
- כל הרשתות: `repeat(auto-fit, minmax(Npx, 1fr))` — נזילות, בלי media queries. מינימומים: 340px לכרטיסים, 330px לפיצול, 320px לפרויקטים, 240px למסלולים, 210px לפוטר.

### אינטראקציה ואנימציה — הרשימה המלאה

כל אלה קיימים ב-`style.css` ובעיצוב המקורי. אין להוריד אף אחד מהם:

1. **טרנזישן גלובלי** על `button, a, summary, input, select, textarea`:  
   `background-color .16s ease, color .16s ease, border-color .16s ease, opacity .16s ease, box-shadow .16s ease, transform .1s ease`
2. **שקיעת לחיצה**: `button:active, a:active { transform: translateY(1px) }` — נותן תחושת כפתור פיזי.
3. **כפתור כתום**: hover מבהיר ל-`#F7972E`, active מכהה ל-`#D66A10`.
4. **כפתור כחול**: hover `#162E73`, active `#102454`.
5. **כפתור מסגרת**: hover מתמלא ב-`#15171C` עם טקסט `#F4F4F2`; active שחור מלא.
6. **כפתור על כחול** (`.dx-btn--onblue`): hover מתמלא כתום + מסגרת כתומה.
7. **ניווט**: hover כתום, active כתום כהה; לעמוד הפעיל פס כתום 4px ב-`::after` בתחתית.
8. **לוגו**: hover `opacity: .7`.
9. **קוביות** (`.dx-card`, `.dx-blue-card`, `.dx-box__c`, `.dx-article`): רקע מתבהר + **פס כתום 7px נכנס מלמטה** דרך `inset box-shadow`, ב-.18s. זה האפקט המרכזי של האתר.
10. **אקורדיון**: `summary:hover` וכן `details[open] summary` הופכים לכחול; ה-`+` נשאר כתום וסטטי (במכוון — לא מסתובב).
11. **שדות טופס**: hover ו-focus מחליפים מסגרת לכחול; `:focus-visible` נותן טבעת כתומה 2px עם offset.
12. **גלילה חלקה**: `html { scroll-behavior: smooth }` — לעוגן `#process`.
13. **טופס**: שליחה ב-AJAX, בלי רענון; הטופס מוחלף בפאנל "קיבלנו. נחזור אליך." עם קו כתום.
14. **`prefers-reduced-motion`**: כל האנימציות מתבטלות. חובה להשאיר.

### פונקציונליות

- **טופס לידים** — `inc/leads.php`. שומר כל ליד כפוסט פרטי (*לידים* בתפריט הניהול), שולח מייל, כולל honeypot נגד ספאם ו-nonce. עובד גם בלי JavaScript (POST רגיל).
- **פרויקטים לפני/אחרי** — סוג תוכן `dx_project`. תמונת "אחרי" = התמונה הראשית; "לפני" = מזהה מדיה בתיבה בצד. בלי פרויקטים מוצגים שני כרטיסים ריקים כמו בעיצוב.
- **מאמרים** — פוסטים רגילים של וורדפרס. הקטגוריה הראשונה מוצגת ככיתוב כתום על הכרטיס.
- **תוכן טקסטואלי** — הכל ב-`inc/content.php`, כל מערך עטוף ב-`apply_filters`. אפשר להחליף ל-ACF בלי לגעת בתבנית.

## מה במכוון *לא* עשינו

- **בלי page builder** (אלמנטור/דיבי). הפריסה נזילה ומבוססת גריד; בילדר היה שובר את הגבולות של 2px ואת המרווחים הנזילים.
- **בלי תוסף טפסים.** הטופס במקום, מאובטח ב-nonce, נשמר בלוח הניהול. אם הלקוח רוצה CF7 — להחליף רק את הטופס ב-`template-parts/lead-form.php`.
- **בלי JS מלבד 30 שורות.** כל ההתנהגות שאפשר — ב-CSS. האקורדיון הוא `<details>` נטיבי.
- **בלי media queries לפריסה** (רק 3 תיקוני נשימה למובייל). `auto-fit` + `clamp` עושים את העבודה.
