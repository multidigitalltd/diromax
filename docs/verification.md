# תוצאות הבדיקה

הערכה נבדקה על התקנת WordPress 7.0.2 חיה עם PHP 8.4, כולל הרצת המתקין,
רינדור כל סוגי העמודים, שליחת טפסים והרצת axe-core בדפדפן.

## בדיקת מבנה

תשעה סוגי עמודים, כולם עוברים: כותרת H1 אחת, ללא קפיצות בהיררכיית הכותרות,
ללא מזהים כפולים, ללא הפניות ARIA שבורות, `alt` לכל תמונה, תווית לכל שדה,
שם נגיש לכל קישור וכפתור, וקינון רשימות תקין.

## ניגודיות צבעים (חישוב ישיר)

23 צמדי צבע נבדקו בכל אחד מחמשת מצבי הפלטה — רגיל, ניגודיות גבוהה, היפוך,
גווני אפור, והיפוך+אפור. כולם עוברים 4.5:1 לטקסט רגיל ו-3:1 לרכיבי ממשק.

סימון המיקוד הוא סימון מורכב — טבעת דיו וטבעת כתומה — ומגיע ל-3:1 לפחות
מול כל משטח בכל מצב:

## מקלדת ותצוגה

- מעבר על 45 עצירות Tab בעמוד הבית — אף רכיב ממוקד אינו מוסתר מאחורי
  הכותרת הדביקה או מאחורי סרגל הקשר (WCAG 2.4.11).
- עוגן `#process` נוחת מתחת לכותרת הדביקה ולא מאחוריה.
- ESC סוגר את פאנל הנגישות ומחזיר את המיקוד לכפתור הפותח.
- ההעדפות נשמרות במעבר בין עמודים.
- הגדלת טקסט ל-160% — ללא גלילה אופקית.
- רוחב 320px ו-390px — ללא גלילה אופקית באף אחד משבעת העמודים (WCAG 1.4.10).

## טופס הלידים

| בדיקה | תוצאה |
|---|---|
| נקודת REST ל-nonce | `{"nonce":"..."}` עם `Cache-Control: no-store` |
| שליחה תקינה | `{"success":true}`, הליד נשמר עם כל השדות |
| nonce שגוי | נדחה |
| שדות חובה חסרים | נדחה עם הודעה |
| טלפון לא תקין | נדחה עם הודעה |
| Honeypot מלא | מחזיר הצלחה ולא שומר דבר |
| ערך `select` שלא הוצע בטופס | נשמר ריק — לא מתקבל כטקסט חופשי |
| הגבלת קצב | הפנייה השישית בשעה נדחית |
| ללא JavaScript | 302 חזרה לעמוד עם דגל הצלחה או שגיאה |
| דגל לא מוכר ב-URL | נדחה, לא מוזרק לעמוד |

## שגיאות PHP

`WP_DEBUG` ו-`WP_DEBUG_DISPLAY` פעילים לאורך כל הבדיקה.
אפס Warning, אפס Notice, אפס Deprecated, אפס Fatal בכל העמודים.
`php -l` נקי על כל 28 קובצי ה-PHP תחת PHP 8.4.

## שגיאות דפדפן

אפס שגיאות קונסולה ואפס בקשות שנכשלו (404) בכל העמודים.

## עורך התוכן (גרסה 2.1)

נבדק מקצה לקצה בדפדפן, מול התקנת וורדפרס חיה:

|---|---|
| טעינת המסך | שבע לשוניות, 127 שדות |
| עריכת כותרת עם שבירת שורה | נשמרה, ומוצגת באתר עם `<br>` |
| עריכת כפתור | הטקסט החדש מופיע באתר |
| הוספת שורה לרשימה | הנקודה הרביעית נוספה והוצגה |
| מה נשמר בפועל | 3 מפתחות מתוך 58 בקבוצה — 563 בתים |
| `autoload` | `off` |
| שדה שלא נערך | ממשיך לקחת את ברירת המחדל מהערכה |
| "החזרה לטקסט המקורי" | מחק את הקבוצה והחזיר את הכל למקור |

## תמונת ברירת מחדל לפוסטים

| בדיקה | תוצאה |
